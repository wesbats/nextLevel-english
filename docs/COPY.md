## Notas para os Desenvolvedores (React/Tailwind/Shadcn)

- **Cores & Dark Mode:** A plataforma usa primariamente `Electric Blue (#0066FF)` e `Neon Cyan (#00D4FF)`. Importante configurar o tema do Tailwind para aceitar as variações da paleta descritas no `BRAND.md`. O site institucional deve suportar System Preference (Dark/Light mode) usando `Deep Navy (#0A0E1A)` no Dark e `Light Fog (#F0F4FF)` no Light.
- **Tipografia:** Configurar fontes via Google Fonts no arquivo global/Tailwind config: `Sora` (ou `Space Grotesk`) para headings (`font-display`) e `Inter` para o body (`font-sans`). Para números de XP/Estatísticas no Hero, aplicar `JetBrains Mono` (`font-mono`).
- **Componentes Shadcn Recomendados:** - `Accordion` para a seção de FAQ.
  - `Tabs` para alternar entre a visualização de features dos perfis (Kids / Teen / Adult) na Seção 3.
  - `Card` com efeitos de hover/glow para a Seção de Modos e Prova Social.
  - `Button` configurado com tamanhos `lg` para os CTAs principais, usando a cor `Electric Blue` como `bg-primary`.
- **Efeitos:** Utilizar gradientes diagonais de fundo (via classes nativas do Tailwind como `bg-gradient-to-br`) e sombras (`drop-shadow` / `shadow-blue-500/50`) para ressaltar a identidade "gamer" descrita no Brandbook.
- Os CTAs no final de cada seção devem ancorar para as lojas de app (links provisórios podem ser colocados como `href="#"`).
